## Code of Conduct

Contributing to `forgejo-cli` should be a safe, inclusive, and welcoming process.
To facilitate this, all contributors are bound by the
[Forgejo Code of Conduct](https://codeberg.org/forgejo/code-of-conduct). If
someone's behavior at any point makes you feel unsafe or uncomfortable, or in
some other way violates the Code of Conduct, reach out to Forgejo's
[Moderation Team](https://codeberg.org/forgejo/governance/src/branch/main/TEAMS.md#moderation).
They will do their best to help you and resolve the situation.

## Coding
### Style
All code submissions must be formatted with `rustfmt`/`cargo fmt`. This is checked in CI to ensure proper formatting before a PR is merged.

Commit messages should follow the [Conventional Commit standard](https://www.conventionalcommits.org/en/v1.0.0/). There's no expectation for pull request titles to follow this though.

## Localization

`forgejo-cli`'s localization is done on
[Codeberg Translate](https://translate.codeberg.org/projects/forgejo-cli/forgejo-cli/),
and uses the Fluent localization system. It is recommended you first familiarize
yourself with Fluent if you are not already. You can do so on
[Fluent's website](https://projectfluent.org/) 

If your language hasn't been added yet, you can start work on it by going to the
"Languages" tab on Weblate and clicking on the plus symbol to the top left of
the languages list.
